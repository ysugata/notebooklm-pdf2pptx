# 編集可能化スキル

非エンジニアの依頼者に代わって変換を実行し、結果を分かりやすく報告する。

## 手順

1. 環境確認: `.venv/bin/python` が無ければ初回セットアップを実行:
   `python3 bootstrap.py --with-lama --with-fonts`(数分かかる旨を先に伝える)
2. 変換:
   ```
   .venv/bin/python convert.py "<入力ファイル>" -o "<入力名>_editable.pptx" --inpaint auto --no-open-report
   ```
   - 大きい資料は時間がかかる(目安: 60ページで1時間)。途中で止まっても
     同じコマンドの再実行で続きから再開される
   - 別資料を続けて変換するときは `--work-dir work_<名前>` で分ける
   ✓ 確認: ログが完了メッセージ(または「低信頼OCR行があります」)で終わって
   いること。エラーやトレースバックで止まっていたら原因を調べてから進む。
3. 検証: `.venv/bin/python tools/smoke_test.py "<出力.pptx>"`
   ✓ 確認: 「OK: 構造検査に問題なし」が出ること。出なければ報告に含める。
4. 報告(専門用語を避ける):
   - 何枚変換され、いくつの文字が編集可能になったか
   - 自動修正された文字化けの件数(reviewの「文字化け予測修正」)
   - 要確認箇所が残っていたら、**そのままチャットで回答を始める**
     (/pptx-fix-garble の対話式回答が既定。変換は `--no-open-report` で実行し、
     ブラウザとチャットの二重提示を避ける。ユーザーが「後で」と言ったら
     レポートの場所を伝えて終える)
   - 出力ファイルの場所

## 完了条件(全て満たすまで終了しない)

- [ ] smoke_test が OK
- [ ] 報告に4点(枚数・編集可能文字数・自動修正件数・要確認件数と場所)
- [ ] 実行できなかった検証があれば理由を報告に明記

## 注意

- 変換済み文字はクリックすればPowerPointで普通に編集できる
- ごく一部、照合できない装飾文字は画像のまま残る(報告に含める)
